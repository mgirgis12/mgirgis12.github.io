# Learning TypeScript One Step at a Time

## My Experience with TypeScript

Before this class, I had experience with other programming languages, but TypeScript was new to me. At first, the syntax was one of the hardest parts for me. I had to get used to declaring types and understanding how functions, loops, arrays, and classes are written in TypeScript. Even when I understood what I wanted the program to do, sometimes I did not know the correct syntax to make it work.

As I continued practicing, TypeScript started to make more sense. The Jamba Juice assignments helped me understand classes, constructors, arrays, and objects better. I also learned how different classes can work together in one program. I still need more practice with the syntax, but I feel more comfortable reading TypeScript code now than I did when I started.

## TypeScript and Software Engineering

I think TypeScript can be a good language for software engineering because it can catch some mistakes before the program runs. Declaring types can feel like extra work when I am writing the code, but it also makes it clearer what kind of information a variable or function should use. I can see how this could become more helpful when working on larger programs or working with other people.

One thing I am learning is that knowing programming concepts and knowing the syntax are different. Sometimes I understand the idea behind a loop, function, or class, but I still have trouble remembering exactly how to write it. Practicing TypeScript has helped me work on both of these skills.

## Learning Through WODs

The practice WODs are different from the way I normally learn programming. Having a limited amount of time makes them stressful because I usually like to work through code slowly and understand each step. When I am watching the time, I sometimes focus more on finishing than understanding what I am doing.

At the same time, I think the practice can be useful. Repeating programming problems helps me become more familiar with the syntax and recognize what I need to do faster. I think this style of learning can work for me as long as I continue practicing before the timed WODs. My goal is not only to finish faster, but also to understand why my code works.

## Moving Forward

I still have a lot to learn about TypeScript, but I have already become more comfortable with it. I want to continue improving my understanding of classes, functions, loops, and how different parts of a program work together. Since I am more interested in hardware and embedded systems, software is not always the easiest part of computer engineering for me, but I know programming is an important skill to have. Learning TypeScript is giving me more practice thinking through programming problems and becoming more confident when working with code.
